# Tests and independent review pack

- Define acceptance criteria and run the smallest relevant checks, then broader checks if feasible.
- Record exact commands, exit status, observed coverage and any skipped checks.
- Reviewer should inspect implementation and test evidence, not just the builder's narrative.
- If independent reviewer unavailable, say so plainly. Use bounded fix/retest attempts and escalate persistent blockers.
- Do not call a project complete when checks fail or acceptance requirements remain unmet.
