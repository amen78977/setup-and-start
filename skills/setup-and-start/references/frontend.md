# UI/UX pack — quality gate, not generic CSS

- Before coding: identify audience, primary task, navigation, layout hierarchy, design tokens, responsive breakpoints, accessibility and language direction.
- Create a coherent visual system: type scale, spacing, color contrast, buttons, input states, empty/loading/error states; reuse components.
- Verify at desktop and phone sizes; check keyboard navigation, meaningful labels, focus, contrast and reduced motion.
- For Arabic interfaces test `dir=rtl`, mixed Arabic/English and number/currency alignment. Do not mirror brand logos or charts blindly.
- Use an available browser tool for screenshots/interactions when permitted; visual claims require observed evidence. Fix issues and repeat.
- Inspirations: `nextlevelbuilder/ui-ux-pro-max-skill`, Anthropic `frontend-design`, `vercel-labs/web-interface-guidelines`; external skills require explicit install/review.
